## 🚀 Установка
1. Скачайте Outpost3Linux.lua
2. Создайте LocalScript в StarterPlayerScripts
3. Вставьте код
4. Нажмите Play
5. TAB — терминал

## ⌨️ Горячие клавиши
- TAB — терминал
- F — полёт
- G — бессмертие
- N — ноклип
- I — невидимость
- H — лечение
